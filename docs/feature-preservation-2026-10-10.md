## Omissions and reference adjustments

The references omit county filtering, complete inventory columns, gas and separate average/maximum pressure, W14/date and permit interval context, individual report selection, the full report table, complete QC/dictionary JSON, legacy/source-specific exports, actual CLI replay, failure/no-result history, invalid registry entries, four node inspection panels, raw evidence and history outside the acquisition scope. These remain accessible. Sorting and chart metric/zoom controls were specifically audited and do not exist in the current implementation; pictures do not authorize inventing them.

Global Find & collect/My datasets/Collection history/Help never display an unrelated dataset header/tabs. Six dataset tabs share identity/version/period. Collection details binds to a verified associated run; independent history inspection is explicitly global and never silently switches the opened dataset. The existing server returns completed run evidence, not live stage events: current Collect progress says waiting for recorded completion, never simulated sub-stage success.

New UI behavior requested by this brief: library, overview, dedicated quality/sources/downloads views, global history/Help, current-request steps and explicit result handoff, restoration of URL selections, and local time display. Existing API/data/export/normalization contracts and the three actual stages remain unchanged.
